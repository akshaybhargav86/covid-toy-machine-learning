# covid-toy-machine-learning
COVID Toy is a beginner-level Machine Learning project developed to practice data preprocessing, exploratory data analysis, and machine learning model implementation using a COVID-related toy dataset.

The project focuses on understanding the dataset, preparing features, exploring relationships between variables, and applying machine learning techniques to gain practical experience with predictive modeling.

**Key Areas Covered:**
- Dataset Exploration
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Understanding and Selection
- Machine Learning Model Implementation
- Model Evaluation

**Tools & Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

This project is part of my continuous learning journey in Data Science and Machine Learning.
